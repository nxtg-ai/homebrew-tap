# NXTG-AI Homebrew Tap

Homebrew formulae for [NXTG-AI](https://github.com/nxtg-ai) tools.

## Install

```bash
brew tap nxtg-ai/tap
brew install forge
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| `forge` | Universal coordination engine for AI-powered development — orchestrates Claude, Codex, and Gemini as a team |

## Upgrade

```bash
brew upgrade forge
```
